# Chrome Web Store listing copy

**Name:** Diary Exporter for MyFitnessPal

**Summary (132 chars max):**
Export your entire MyFitnessPal food diary — any date range, not just the last year — to a CSV file. Runs locally in your browser.

**Category:** Productivity → Tools

**Description:**
MyFitnessPal's built-in export only covers the most recent 12 months. If you've been logging for years, this extension gets the rest.

Open myfitnesspal.com, click the extension icon, pick a date range (your account's full history is prefilled), and press Export. Every food entry you've ever logged is written to a CSV file — date, meal, food name, brand, servings, and the full nutrient breakdown (calories, carbs, fat, protein, fiber, sugar, sodium, cholesterol, saturated/trans/mono/poly fats, potassium, calcium, iron, vitamins A, C and D) — ready for Excel, Google Sheets, or your own analysis.

• Any date range, from your first log to today
• One row per food entry, with 33 columns of detail
• Live progress; close the popup and come back — the export keeps running
• Automatic retries and window-splitting for reliability
• Runs entirely in your browser using your existing login. No accounts, no servers, no tracking.

This extension is not affiliated with or endorsed by MyFitnessPal, Inc. It uses the same requests the MyFitnessPal website makes; if MyFitnessPal changes its site, an update may be needed.

**Single purpose:** Export the user's own MyFitnessPal food diary to a CSV file.

**Permission justifications:**
- activeTab, scripting — run the exporter inside the MyFitnessPal tab the user is viewing, only after the user clicks the extension icon. No standing host access is requested.
- downloads — save the generated CSV to the user's computer.

**Data usage disclosure:** Tick Health information (food diary entries), Website content (diary data read from myfitnesspal.com), and Personally identifiable information (the MyFitnessPal username, stored locally to prefill the form). All data is processed in the browser and written to a local CSV; nothing is transmitted to the developer or any third party. Certify all three statements (no sale/transfer, no unrelated use, no creditworthiness use). Remote code: none.
