# Privacy Policy — Diary Exporter for MyFitnessPal

_Last updated: 2026-09-10_

Diary Exporter for MyFitnessPal ("the extension") helps you download your own MyFitnessPal food diary as a CSV file.

**What the extension accesses.** When you start an export, the extension runs inside the MyFitnessPal tab you have open and requests your diary data from MyFitnessPal's servers using the login session already present in your browser. It reads only the data MyFitnessPal returns for your account and the date range you chose.

**Where the data goes.** The diary data is assembled into a CSV file in your browser and saved to your computer through Chrome's download manager. It is never transmitted to the extension's author or to any third party. The extension has no server of its own.

**What is stored.** The extension remembers the username and start date you last entered, in the browser's local storage for the extension, so the form is prefilled next time. Nothing else is stored, and this can be cleared by removing the extension.

**Analytics and tracking.** None. The extension contains no analytics, advertising, or tracking code.

**Permissions.** `activeTab` and `scripting` let the extension run in the MyFitnessPal tab you are viewing, and only after you click the extension icon; `downloads` lets it save the CSV. The extension requests no standing access to any website.

**Changes.** If this policy changes, the updated version will be published alongside the extension and at the URL linked from the Chrome Web Store listing.

**Contact.** Questions or concerns can be raised by opening an issue at https://github.com/rodmhgl/mfp-diary-exporter/issues, or through the support link on the Chrome Web Store listing.

The extension is not affiliated with or endorsed by MyFitnessPal, Inc.
